## ⚠️ Read this first — what this list is and isn't

> Every one of the 112 confident off-M-CSA candidates is reviewed Swiss-Prot with 'Evidence at protein level' — i.e. already experimentally characterized. The annotation-anchored bronze pool contains NO unknown-function proteins, so it cannot yield a novel benchtop discovery target. It is a validation set, not a discovery set.

So none of the tiers below is an *unknown-function* target. Tier 1 is a **blind validation**
panel (predict → confirm against the enzyme's established EC — cheap Gate-2 evidence, no wet
lab strictly required). Tier 2 is the genuinely interesting **multi-cofactor** finding. The
path to a true *discovery* benchtop target is at the bottom.

## The real next step for a NOVEL benchtop target

> For a genuinely novel (unknown-function) benchtop target, re-run the SAME engine over an UNCHARACTERIZED in-family pool (TrEMBL / 'Predicted'/'Inferred from homology' / no experimental EC), fetch AlphaFold structures, foldseek vs the M-CSA atlas, apply the same fold>=0.70 gate. That swap of input pool is the only missing step and is bounded.

Concretely: pull in-family UniProt entries that are **unreviewed / 'Predicted' / no experimental
EC**, fetch their AlphaFold models, foldseek them against the atlas, apply the same TM ≥ 0.70 gate.
That produces a shortlist of confident mechanism calls on proteins **no one has characterized** —
which is what you would actually take to the bench to *discover* something, not just re-confirm it.
