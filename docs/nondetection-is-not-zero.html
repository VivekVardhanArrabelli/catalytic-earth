Nondetection is not zero.

Two enzyme variants. Two conclusions almost anyone would draw from the headline result. The reviewed record contradicts both — and says exactly how far it can be trusted.

Mandelate racemase · H297N

No detectable racemase activity, so catalysis is gone.

It still catalyses (S)-mandelate α-proton exchange, 3.3-fold below wild type. The impairment is selective, not total.

Transketolase · H473N

The competing byproduct is gone, so more target product.

Target product went down — 5.5 mM against 10.5 mM for wild type in the same mixture.

Does “no racemase activity” mean catalysis is lost?

Mandelate racemase · Pseudomonas putida · M-CSA M0187 · variant H297N

Filtering the case to isotope-exchange endpoints returns two observations from the same paper. They point in opposite directions, and that is the finding: the variant is impaired on one endpoint while retaining another.

Observations returned

SubstrateResultValueConditions
(S)-mandelate measured 3.3× below WT pD 7.5, D₂O
(R)-mandelate not detected — pD 7.5, D₂O

“H297N catalyzes the stereospecific exchange … (S)- but not (R)-mandelate”

PMID 1909893 · PubMed Abstract/AbstractText

What this does not establish

  • Exchange is not net racemization. Retained exchange counters total abolition of catalysis; it does not restore the racemase reaction.
  • The (R)-mandelate nondetection carries no numeric detection limit in the source. It is not a rate of zero.
  • No net racemization direction and no elementary proton-transfer timing follow.
  • Structure 1MNS is reference geometry — inhibitor-bound, chemically modified. Its primary citation, PMID 8292591, is a different source role from the functional paper above. There is no H297N mutant structure here.
catalytic-earth atlas-mechanism-evidence \
  --variant H297N --endpoint isotope_exchange

Did losing the competing product improve the target?

Transketolase · E. coli · comparison tk_2020:H473N:DHB_accumulation

H473N accumulates no detectable erythrulose, the competing donor-route product. The intuitive read is improved selectivity toward the target. The same experiment shows target accumulation falling by roughly half.

What this does not establish

  • These are accumulated concentrations at one time point — not rates, not microscopic selectivity.
  • The erythrulose nondetection is flagged is_zero_rate: false with no numeric limit. Nondetection does not establish absent flux, and the route is measured in a mixture that still contains pyruvate.
  • The comparison's own scope excludes any erythrulose ratio, any DHB/erythrulose selectivity ratio, propagated uncertainty and significance.
  • No donor-half rate, no pyruvate affinity, no isolated H473N mechanism, and no transfer to another construct or study.
python scripts/query_atlas_perturbations.py \
  --comparison tk_2020:H473N:DHB_accumulation

The reason a working scientist can use this one is that every result arrives carrying its own limits — which endpoint was measured, which paper supports it, which structure is only reference geometry, and where a nondetection has no threshold behind it. Those limits are in the records themselves, not appended afterwards by a reader.

Both cases here are curated demonstrations — not held-out validation, not a benchmark, and not new biological findings. Saying so is the same discipline as the boxes above.
