# Archived — lab-experiment explorations (June 2026)

These documents explored taking an atlas prediction to a wet lab. They are
**SUPERSEDED** and should **not** be acted on, for a documented reason:

> The decisive orphan search (`artifacts/v3_decisive_orphan_search_current702_20260630.json`,
> `work/decisive_orphan_search_20260630.md`) showed that **no lab experiment can isolate the
> atlas's unique value for its current 4 families** — those mechanisms live in
> sequence-recognisable superfamilies, so sequence/Pfam always recovers the mechanism class
> and the atlas is never the only path. A lab confirmation here would re-confirm what Pfam
> already knows, not prove the atlas.

They are kept for the record (candidate sequences, assay protocols, handoff format remain
reusable if/when the atlas is extended to sequence-cryptic mechanisms). The atlas's *proven*
value (twilight-zone accuracy, fail-safe abstention, mechanism-searchability) is unaffected;
see `docs/decision_log.md` (2026-06-30) and `docs/atlas_extension_scoping_20260630.md`.
