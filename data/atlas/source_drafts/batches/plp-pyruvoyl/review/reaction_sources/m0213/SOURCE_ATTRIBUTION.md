# M0213 reaction-correspondence source attribution

This directory retains official structured evidence for the reviewed, record-level correspondence between [M-CSA M0213](https://www.ebi.ac.uk/thornton-srv/m-csa/entry/213/) and the left-to-right Rhea reaction [RHEA:20250](https://www.rhea-db.org/rhea/20250), whose direction-undefined master is [RHEA:20249](https://www.rhea-db.org/rhea/20249). The M-CSA snapshot and UniProtKB P10724 record are reused at their existing repository paths and are not duplicated here.

The Rhea master query, direction map, Rhea-to-M-CSA cross-reference map, SPARQL result, and two Rhea-hosted ChEBI participant mol files were captured on 2026-09-06. Each committed upstream file is copied byte-for-byte. Rhea's SPARQL response identifies release `2026_03`; the FTP receipts record `Last-Modified: Wed, 02 Sep 2026 14:00:00 GMT`. The acquisition ledger includes unsuccessful probes as well as successful responses. Header-only directed searches and the HTTP 403 Cloudflare HTML returned for the attempted RXN request are not chemical evidence and are not redistributed as positive source artifacts.

`reaction_evidence_projection.json` is a project-authored selection from these sources. Official Rhea rows establish a cross-reference to the M0213 record; they do not directly bind an M-CSA mechanism proposal or step. The proposal's declared L-to-D direction is a separate M-CSA witness. The endpoint CIP/charge readout is a reviewed project diagnostic from retained source drawings and participant structures, not upstream atom correspondence, an exact species normalization, or a validated trajectory. Current [ChemAxon CML documentation](https://docs.chemaxon.com/latest/formats_cml.html) is cited for W/H format semantics but its body is not redistributed; the retained MRV declares version 18.11.0. The [IUBMB EC 5.1.1.1 page](https://iubmb.qmul.ac.uk/enzyme/EC5/1/1/1.html) is citation-only corroboration and is not a bound artifact.

`computational_depiction_audit.json` is project output from RDKit 2025.03.3 applied separately to each retained MRV panel. `audit_depiction.py` is its optional hash-pinned reproducer and also verifies the two reference participant files before computing. Neither file is an upstream claim or a production runtime dependency, and the readout is not evidence of a chemically coherent trajectory.

No atom map is asserted. The committed participant mol files have no nonzero atom mapping numbers, and shared local indices across separate molecules or M-CSA panels must not be interpreted as a cross-reaction atom correspondence.
